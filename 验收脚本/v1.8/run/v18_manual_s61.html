3 新功能怎么用（用户视角）

  • 挂在「待批」上刷新页面：回来点进那条会话能看见两张收尾卡——原来那张变成「⏹ 待批 · run_python · 随中断取消 · 等了 5.2s」（不再是「✔ 允许」那句冻结措辞），底下多一条「⏹ 已中断 · 审批空等 5.2s」，正文写清「这一题有 1 项审批没等来点击」「其中干等 5.2s 在等人点审批」「想接着做，重新提问即可」。状态条那一档叫已中断，不叫已停止。⚠️ 首屏那一刷有时是空的（约 0.4~0.8 秒的窗口，这就是 #42），再刷一次或点侧栏就有了。
  • 计划面板：提问后第一件事是屏幕上方多出「🧭 本题计划」那一格，写清这份计划要干什么、要动哪几个工具，带 ✔ 允许／✖ 拒绝。点 ✔ → 工具审批照常弹、跑完，批准过的那份计划进记忆（追问时模型读得到）；点 ✖ 或没人点等到超时 → 状态「计划未批准」，那一题一个工具都没跑；按 ■ → 状态「已停止」（不会串成「计划未批准」）。规划每题只出一份（interval=8 配 max_steps=8，第 9 步够不着）。
  • 越界／相对路径的报错：问它删根外的目录，报错不再只有一句「越界：X 不在白名单根目录之下」，而是「这套工具只服务这一个根／没有删除·移动·重命名／请你在自己的终端执行」，并且不再让你去找系统管理员。给一个相对路径而它不存在时，会说清「我只能接到这个根底下再找，根外有没有同名目录我读不到」。
  • 重复调用：同一题里第 2 次发出同工具同参数的调用不再执行，卡片变「⚪ 重复未执行 1/1」，模型收到一句「本题内这已经是第 2 次发出完全一样的调用…请换参数」；第 3 次（超过上限 2）当场在步边界收场，卡片「⛔ 重复熔断 1/1」、状态档「重复熔断」、收尾气泡写明「本题挡下的重复调用超过了上限 2 次，已在步边界收场」。换一题从 0 起算；命令行 python my_coding_agent.py 那一路不经过界面，也不会被这层拦。
